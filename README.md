# Golden Bomb Jump Script for MMV Game

This script is designed for the MMV game on Roblox, providing an auto-jump functionality when a golden bomb is touched. It is a server-side script that enhances the player experience by automatically making the player jump upon interaction with the golden bomb.

## Install

1. Place the `golden_bomb.lua` script in the `ServerScriptService` folder of your Roblox game.
2. Attach the script to the golden bomb model in the game workspace.

## Use

1. Ensure the golden bomb model is properly placed in the game workspace.
2. The script will automatically detect when the golden bomb is touched by a player.
3. Upon touching the golden bomb, the player will automatically jump.
